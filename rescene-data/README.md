# 리센느 제작 자료

리센느 시리즈 롱폼, 해외반응, 패러디 영상을 만들 때 쓰는 자료입니다. 2026년 11월 25일 기준.

- `리센느_제작_자료집.html` — 내려받아 브라우저로 여는 자료집 (탭: 잘된 영상 분석 · 해외 반응 · 밈·화제 · 기본 정보·연대기 · 영상 목록)
- `data/videos_ranking.csv` — 리센느 관련 숏폼(100만 회 이상) 1,102개 · 롱폼(10만 회 이상) 1,099개. 공식 채널·음악방송 제외. 엑셀로 열 수 있습니다.
- `data/videos_all.json` — 수집한 리센느 관련 영상 전체 (조회수·채널·업로드·길이)
- `data/d_*.json` — 해외반응·서사·패러디 장르별 영상, 통계, 분석 요약
- `data/c_*.json` — 해외 댓글(작성자 이름 없음, 번역 포함), 해외 리액션 영상, 해외 기사·커뮤니티
- `data/b_*.json` — 밈 33개의 대표 영상과 유래·대사·패러디 아이디어·주의점 (출처 포함)
- `data/a_facts.json` — 멤버, 음반, 연대기, 차트·수상, 예능, 광고, 논란, 해외 활동 (출처 포함)

참고: 사실 정보는 출처끼리 다른 경우가 있어 `a_facts.json`의 `open_questions`와 각 항목의 출처를 확인하세요. 개그맨 이선민은 원이의 실제 삼촌이 아닙니다(웹예능 '나의 연수 아저씨'에서 생긴 호칭). 레딧·X·allkpop 등은 자동 접근을 막아 해외 커뮤니티 자료가 기사 인용 위주입니다.
