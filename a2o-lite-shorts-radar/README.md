# A2O LITE 쇼츠 레이더

A2O LITE 영상을 올린 YouTube 채널(일반 2,195개 · 공식 3개 · 음악 12개, 2026년 11월 2일 기준)에 최근 올라온 **A2O LITE 쇼츠만** 골라서 보여 주는 프로그램입니다.

- **최근 N일 · 조회수 기준**: 최근 3일 안에 올라온 A2O LITE 쇼츠 중 조회수 100만 회 이상인 영상과 그 채널
- **전날 대비 증가**: A2O LITE 쇼츠 하나의 조회수가 24시간 전 수집 기록보다 30만 회 이상 오른 영상과 그 채널

A2O LITE 쇼츠는 제목에 A2O LITE·에이투오 라이트·에투라 같은 그룹명이 있거나, 제목에 멤버 이름이나 NEON이 있고 제목·설명·태그에 A2O가 함께 있는 영상입니다. A2O LITE 공식 채널 영상은 모두 포함합니다.

기준 숫자(3일, 100만, 30만)는 화면에서 바꿀 수 있습니다.

## 쓰는 법 (윈도우)

1. `A2O_LITE_쇼츠레이더.html`을 내려받아 더블클릭합니다. 크롬이나 엣지에서 열립니다.
2. 처음 한 번은 아래 **설정**을 열어 YouTube Data API v3 키를 넣고 **키 저장**을 누릅니다.
3. 위에서 일반 · 공식 · 음악 중 하나를 고르고 **수집**을 누릅니다.
4. 결과는 채널별로 묶여 나오며, 썸네일이나 제목을 누르면 쇼츠가 열립니다. **CSV로 내려받기**로 엑셀 파일을 받을 수 있습니다.

## 알아 둘 점

- 전날 대비 결과는 처음 수집한 다음 날(12시간 이상 지난 뒤)부터 나옵니다. 수집 기록은 그 컴퓨터의 그 브라우저에만 저장됩니다.
- 쇼츠는 길이 3분 이하 영상으로 판단합니다. 채널마다 최근 영상 20개와, 최근 N일(화면에서 정한 일수) 안에 올라온 영상을 모두 확인합니다.
- 일반 채널 전체 수집 1회에 API 약 3,100 단위를 씁니다. 무료 한도는 하루 10,000 단위(한국 시간 오후 4~5시 초기화)라서 하루 3번 정도 수집할 수 있습니다.
- 채널은 **채널 관리**에서 주소나 @핸들로 추가하고 X로 뺄 수 있습니다.
- 이 저장소의 파일에는 API 키가 들어 있지 않습니다. 키를 파일에 넣어 다른 사람에게 보내지 마세요.
