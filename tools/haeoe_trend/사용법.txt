해외반응 키워드 트렌드 - 사용법
================================

무엇을 하는 프로그램인가요?
  해외반응 36개 주제(지하철, 김밥, bts ...) 중에서
  최근 3일 동안 조회수가 가장 많이 늘어난 주제를 순위로 보여 줍니다.
  주제를 누르면 그 기간에 조회수가 많이 늘어난 영상이 펼쳐집니다.

처음 한 번만: Python 설치
  1. https://www.python.org/downloads/ 에서 Python 3 을 내려받아 설치합니다.
  2. 설치 첫 화면에서 "Add python.exe to PATH" 에 꼭 체크하세요.
  (추가로 설치할 것은 없습니다.)

사용하기
  1. 이 폴더를 원하는 곳(예: 바탕화면\해외반응)에 둡니다.
  2. 실행.bat 을 더블클릭합니다.
  3. 검은 창에서 진행 상황이 나오고, 끝나면 결과.html 이 브라우저로 열립니다.
     - 새 영상 찾기: 약 3~5분
     - 조회수 기록: 약 20~30분 (영상 약 1만 2천 개)

매일 실행해야 하는 이유
  이 프로그램은 실행할 때마다 영상별 조회수를 그날 날짜로 기록하고,
  3일 전 기록과 비교해서 "늘어난 조회수"를 계산합니다.
  - 처음 받은 자료에는 2026-11-01 기록이 들어 있어서, 첫 실행부터 그날 이후 변화가 보입니다.
  - 매일 실행하면 항상 "최근 3일" 순위가 됩니다.
  - 며칠 건너뛰면, 가장 가까운 3일 이전 기록과 비교합니다(화면 위에 비교 기간이 나옵니다).

매일 자동으로 실행하기 (선택)
  매일자동실행_등록.bat 을 더블클릭하면 매일 오전 9시에 자동으로 실행됩니다.
  (컴퓨터가 켜져 있어야 합니다. 자동 실행 때는 브라우저가 열리지 않고 결과.html 만 새로 만들어집니다.)
  해제하려면 매일자동실행_해제.bat 을 실행하세요.

파일 설명
  실행.bat                 직접 실행 (끝나면 결과를 엽니다)
  auto_run.bat             자동 실행용 (직접 누를 필요 없음)
  결과.html                결과 화면 (실행할 때마다 새로 만들어짐)
  trend.db                 날짜별 조회수 기록 (지우면 기록이 처음부터 다시 쌓입니다)
  seed.json                처음 추적할 영상 목록 (지금까지 찾은 해외반응 영상 11,929개)
  keywords.py              36개 주제의 검색어와 판정 규칙 (주제·검색어를 고칠 때)
  haeoe_trend.py           프로그램 본체
  last_run_log.txt         자동 실행 때의 진행 기록

판정 기준 (지금까지 만든 순위표와 같음)
  - 롱폼(3분 이상)만, 쇼츠 제외
  - 제목에 외국을 나타내는 말 + 반응을 나타내는 말 + 한국을 나타내는 말이 모두 있어야 함
  - 방송사·공식 채널·먹방 채널 제외
  - 한 영상에 주제가 여러 개면 제목에서 먼저 나오는 주제 하나에만 넣음
  - 새로 찾은 영상은 조회수 1만 회 이상만 추적

안 될 때
  - "python 을 찾을 수 없습니다": Python 설치 때 PATH 체크를 안 한 경우입니다. 다시 설치하세요.
  - 검색 결과가 0개로 나오면 유튜브 쪽 구조가 바뀐 것일 수 있습니다. 이 폴더와 함께 문의해 주세요.
