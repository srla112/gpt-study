해외반응 키워드 트렌드 (2판) - 사용법
=====================================

무엇을 하는 프로그램인가요?
  해외반응 영상 전체에서 "최근 3일 동안 조회수가 몰린 핵심 키워드"를 찾아 줍니다.
  그 키워드로 다시 검색해서 영상 소재를 고르시라고 만든 프로그램입니다.

결과 화면(결과.html)의 탭
  1. 핵심 키워드     세분화한 키워드 91개(음식 23, 스포츠 13, K콘텐츠 10, 여행·장소 12, 교통 7, 생활·문화 18, 경제·기술·방산 5)의 순위
  2. 분류별          분류를 고르면 그 안에서 어떤 세부 키워드가 뜨는지 (예: 음식 → 한우·김밥·떡볶이 ...)
  3. 새로 뜨는 키워드 사전에 없는데 최근 갑자기 많이 나온 단어 (새 드라마 제목, 새로 뜬 사람 이름 등)
  4. 같은 이야기 묶음 최근 7일 여러 채널이 같은 소재로 올린 영상 묶음 (지금 시장이 몰리는 구체적인 이야기)
  5. 급상승 새 영상   올라온 지 3일 안 된 영상 중 하루 조회수가 가장 빠른 영상 (다음에 뜰 소재)
  6. 터진 영상        채널 평소 조회수보다 3배 이상 터진 영상 = 소재 덕분에 터진 영상
  7. 해외 원본 선점   최근 2주 영어권에서 빠르게 뜨는 한국 관련 원본 영상 (한국 채널들이 다루기 전 소재)
  8. ★ 관심 키워드   ★를 누른 키워드만 모아 보기

키워드마다 보이는 것
  - 늘어난 조회수      최근 3일 동안 그 키워드 영상들의 조회수가 늘어난 양
  - 기회 점수          늘어난 조회수 ÷ (최근 2주 올라온 영상 수 + 2). 높을수록 "수요는 큰데 경쟁은 적은" 키워드
  - 단계              새싹(막 뜨기 시작) / 상승 / 과열(영상이 너무 많음) / 하락 / 유지
  - 상승률            이전 3일보다 이번 3일에 얼마나 더 늘었는지 (기록이 6일 이상 쌓이면 나옴)
  - 작은 채널 성공      구독자 1만 미만 채널이 5만 회 넘긴 영상 수 (따라 만들기 좋은 신호)
  - 터진 영상          채널 평소의 3배 이상 나온 영상 수
  - 잘 되는 국적        어느 나라 사람 반응 영상이 조회수를 가장 많이 가져갔는지
  - 제목 공식         잘 된 제목에 많이 쓴 방식 (따옴표로 시작, "~한 이유", 국적 넣기 등) 비율
  - 추이 그래프        날짜별 증가량 (매일 실행할수록 선이 생깁니다)
  - 버튼              ★ 관심 / 유튜브에서 '해외반응 + 키워드' 검색 / 해외 원본 찾기(영어 검색)
  - 펼치면            조회수가 많이 늘어난 영상(썸네일, 채널, 구독자, 날짜, 늘어난 조회수)

엑셀
  결과_키워드.csv 를 엑셀로 열면 키워드 순위표가 그대로 들어 있습니다.

처음 한 번만: Python 설치
  1. https://www.python.org/downloads/ 에서 Python 3 을 내려받아 설치합니다.
  2. 설치 첫 화면에서 "Add python.exe to PATH" 에 꼭 체크하세요. (추가 설치는 없습니다.)

사용하기
  1. 실행.bat 을 더블클릭합니다.
  2. 진행 상황이 나오고, 끝나면 결과.html 이 브라우저로 열립니다. 한 번에 약 20~40분 걸립니다.
     1/4 해외반응 채널 약 1,100곳의 최근 업로드 확인   (1~2분)
     2/4 해외반응 검색 약 130번 (최신순)               (1분)
     3/4 해외 원본 검색 약 110번 (이번 주 업로드)       (1분)
     4/4 영상 약 1만 개의 정확한 조회수                 (20~30분)
  3. 매일 실행하면 항상 "최근 3일" 기준이 됩니다. 매일자동실행_등록.bat 을 한 번 실행하면 매일 오전 9시에 자동으로 돕니다.
     (처음 받은 자료에는 2026-11-01 기록이 들어 있어서, 첫 실행부터 그날 이후 변화가 보입니다.)

키워드 고치기·추가하기
  dictionary.py 를 메모장으로 열면 분류별 키워드가 있습니다. 한 줄씩 추가하면 됩니다.
    예)  '마라탕': (r'마라탕', 'Korean malatang reaction'),
  앞은 제목에서 찾을 말(여러 개는 | 로 이음), 뒤는 해외 원본을 찾을 영어 검색어입니다.

판정 기준
  - 롱폼(3분 이상)만, 쇼츠 제외
  - 제목에 외국을 나타내는 말 + 반응을 나타내는 말 + 한국을 나타내는 말이 모두 있어야 해외반응으로 봄
  - 방송사·공식 채널·먹방 채널·해외감동사연(나레이션 사연) 제외
  - 1판 기록(trend.db)이 있으면 그대로 이어서 씁니다

파일 설명
  실행.bat / auto_run.bat / 매일자동실행_등록.bat / 매일자동실행_해제.bat   실행용
  결과.html, 결과_키워드.csv     결과 (실행할 때마다 새로 만들어짐)
  trend.db                     날짜별 조회수 기록 (지우면 처음부터 다시 쌓임)
  seed.json, channels.json     처음 추적할 영상 11,929개, 확인할 해외반응 채널 1,034곳
  dictionary.py                키워드 사전 (고쳐도 됨)
  keywords.py, haeoe_trend.py, template.html   프로그램 본체

고장에 강하게
  - 실행할 때 유튜브의 현재 버전 정보를 자동으로 읽어 옵니다.
  - 어느 단계에서 수집이 비정상적으로 적으면 결과 화면 맨 위에 경고가 나옵니다.

안 될 때
  - "python 을 찾을 수 없습니다": Python 설치 때 PATH 체크를 안 한 경우입니다. 다시 설치하세요.
  - 수집이 0개로 나오면 유튜브 쪽 구조가 바뀐 것일 수 있습니다. 검은 창 화면을 캡처해서 문의해 주세요.
