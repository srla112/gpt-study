# 영자의 오늘 운세

영자아씨 채널 댓글에 걸 웹 운세 페이지예요. 이름, 생년월일(양력), 성별을 넣으면 그날의 운세가 큰 글씨로 짧게 나와요.

- 한 줄 제목 (예: "복이 문 두드리는 날")
- 좋아요 / 조심 한 가지씩
- 행운의 색 · 숫자 · 방향
- 영자의 한마디

## 운세는 어떻게 정해지나요
- 태어난 해로 띠를 구하고, 오늘의 일진(간지)을 계산해요.
- 내 띠와 오늘 일지가 육합·삼합이면 좋은 날, 같으면 내 날, 충이면 조심, 원진이면 말조심 날이에요.
- 행운의 색·숫자·방향은 나를 돕는 오행(인성)을 중심으로 정해요.
- 같은 사람은 같은 날 몇 번을 봐도 같은 결과가 나오고, 날짜가 바뀌면 운세도 바뀌어요.

## 고치는 곳
- 영자 그림: `assets/yeongja.png` (배경이 투명한 PNG, 세로형 권장)
- 문구: `fortune.js` 안의 `TEXT`, `GOOD`, `CAREFUL`
- 채널 주소: `index.html` 안의 `CHANNEL_URL`
