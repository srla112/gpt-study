# 영자의 오늘 운세

영자아씨 채널 댓글에 걸 웹 운세 페이지예요. 시니어가 쓰기 쉽게, 글자 입력 없이 **내 띠 → 내 년생** 두 번만 누르면 그날의 운세가 큰 글씨로 짧게 나와요. 다음에 들어오면 바로 내 운세가 보여요.

- 오늘의 사자성어 + 한자 + 쉬운 풀이 (예: 운수대통 運數大通 — 운이 크게 트이는 날)
- 좋은 일 한 문장, 조심 한 문장 (신문 운세 말투)
- 행운의 색 · 숫자
- 카톡으로 보내기 버튼
- 영자의 한마디

## 운세는 어떻게 정해지나요
- 태어난 해로 띠를 구하고, 오늘의 일진(간지)을 계산해요.
- 내 띠와 오늘 일지가 육합·삼합이면 좋은 날, 같으면 내 날, 충이면 조심, 원진이면 말조심 날이에요.
- 행운의 색·숫자는 나를 돕는 오행(인성)을 중심으로 정해요.
- 같은 사람은 같은 날 몇 번을 봐도 같은 결과가 나오고, 날짜가 바뀌면 운세도 바뀌어요.

## 화면 밝기
- 평소에는 밝은 한지색 화면이에요.
- 휴대폰이 다크 모드일 때만 자동으로 진한 갈색 바탕에 미색 글씨로 바뀌어요.
