# 영자의 타로

영자아씨 채널용 시니어 타로 페이지예요.

1. 궁금한 주제를 눌러요: 오늘 하루 / 돈 / 건강 / 가족
2. 카드가 섞여 3장이 깔리면, 마음 가는 한 장을 눌러요.
3. 카드가 뒤집히고, 카드 이름 · 한마디 뜻 · 그 주제에 맞는 한 문장 · 영자 한마디가 나와요.

- 공개 주소: https://srla112.github.io/gpt-study/yeongja-tarot/
- 카드 그림: 라이더-웨이트 타로(1909, 파멜라 콜먼 스미스 그림, 저작권 만료). 위키미디어 공용에서 받아 360px로 줄임.
- 시니어용이라 무서워 보일 수 있는 카드(매달린 사람, 죽음, 악마, 탑)는 빼고 메이저 아르카나 18장만 써요.
- 카드는 정방향만 써요(역방향 없음).

## 고치는 곳
- 카드 문구: `cards.js` (`today`, `money`, `health`, `family`, `say`)
- 주제 이름·아이콘: `cards.js`의 `TAROT_TOPICS`
- 채널 주소: `index.html`의 `CHANNEL_URL`
- 영자 사진: `assets/yeongja.jpg`, 카톡 미리보기: `assets/share.jpg`
