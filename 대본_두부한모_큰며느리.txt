- 두부 : 4장 "엄마 두부 꺼내게 생겼어" → 5장 두부 한 모 → 6장 작은엄마 일화 → 7장 두부부침 "기다려라" → 10장 "두부는 늘 냉장고에 있다" → 11장 새벽의 두부와 친정엄마 이야기 → 12장 SNS 두부부침 사진
- 차가운 두부와 따뜻한 두부 : 5장 냉장고에서 막 꺼낸 두부(꾸짖음) → 11장 냄비에 데운 두부(받아들임)
- 하은이 : 4장 "내가 보고 싶어서 보는 거다" → 5장 큰며느리 "차별이에요" → 12장 큰며느리가 하은이 하원을 맡음
- 눈치 : 3장 "눈치는 없지" → 5장 "눈치가 없는 건 제가 아니었던 거죠", "누구한테 남겨야 할지 알 만큼은 눈치가 있다"
- 상가 농담 : 2장 "상가 1층은 저희 거죠?" → 5장 "그 돈을 누구한테 남겨야 할지"
- 장손 : 2장 "장손 먹을 건데" → 5장 "차별이에요", "제사도 지내 드릴 건데요" → 7장 "장손 엄마가 지금부터 배워야지", "장손 아빠부터 부쳐야지"
- 스마트폰 교실 : 4장 등록 → 7장 화면 캡처
- 미역국 : 콜드오픈 보온통 → 3장 "미역국이 그렇게 짠 줄은 처음 알았습니다"
- 사부인 : 3장 같이 웃음 → 8장 "같이 웃으시면 안 되지요" → 10장 "그날 제가 같이 웃었습니다"
